======================================================================
0. НАЗНАЧЕНИЕ ДОКУМЕНТА
======================================================================

Этот документ является главным функциональным Blueprint финальной игры ECHO SPHERE.

Он отвечает не на вопрос «что реализовать следующим», а на вопрос:
«Как должна работать ECHO SPHERE в своей полноценной версии».

После утверждения документа:
1. существующий код сравнивается с ним;
2. совместимое существующее содержимое сохраняется;
3. отсутствующее реализуется;
4. частично реализованное доводится;
5. противоречащее Blueprint переделывается;
6. затем выполняются баланс, UX, VFX, звук и визуальная полировка.

Этот документ НЕ является копированием Magic Survival.
Magic Survival используется как исследовательский benchmark: изучаются архитектура решений, глубина билдостроения, темп, RNG, мета-прогрессия, синергии, reward loops, расчёты и сильные/слабые стороны.
Названия, персонажи, магии, артефакты, изображения, тексты, конкретные художественные решения и уникальные сущности Magic Survival не копируются.

Главная цель:
получить глубину и системность уровня зрелого survival-roguelite, но сделать игру узнаваемо ECHO SPHERE: пространственное построение сети Spheres является главным механическим отличием.

======================================================================
1. ИССЛЕДОВАТЕЛЬСКИЙ BASELINE: ЧТО МЫ БЕРЁМ ИЗ MAGIC SURVIVAL
======================================================================

Исследование актуальных материалов сообщества Magic Survival показывает несколько важных архитектурных принципов.

1.1. Сильная сторона Magic Survival — не отдельная способность.
Глубина появляется из нескольких слоёв:
Subject/персонаж -> Class -> Magic -> развитие Magic -> Fusion/Ultimate -> Artifact -> Synergy -> Research -> run.

1.2. Artifact является вторым языком билдостроения.
Он может:
- менять глобальные характеристики;
- усиливать конкретную способность;
- менять поведение способности;
- давать самостоятельный эффект;
- участвовать в синергии нескольких артефактов.

1.3. Синергия заставляет игрока думать не только о текущем выборе, но и о будущей конфигурации.
Однако чрезмерная зависимость от случайных выпадений может превращать заранее задуманный build в ожидание нужных трёх карточек.

1.4. Level Up работает как основной генератор решений.
В актуальных руководствах Magic Survival описываются passive-магии, combat-магии, комбинации и дальнейшие усиления. Community guides отдельно отмечают большое количество магий и комбинаций.

1.5. Meta-progression должна давать долгосрочную цель.
Magic Survival использует Research, Class и Subject, а также отдельные валюты.

1.6. Сильный эффект создаёт постепенное накопление слоёв.
Игрок сначала понимает простое действие, затем обнаруживает взаимодействие, затем строит специализацию.

1.7. Слабые стороны, которые ECHO SPHERE НЕ должна повторять:
- чрезмерная зависимость от RNG;
- generic враги без сильной тактической роли;
- перегруженные поздние эффекты, плохо читаемые на поле;
- чрезмерно длинные забеги без достаточной смены контекста;
- слишком много «статиков» вместо поведения.

Исследовательские источники:
- Magic Survival community wiki: классы, research, artifacts, synergies, магии;
- Magic Survival community guides и Reddit;
- Google Play / обзоры;
- Fandom mechanics pages для формул;
- актуальные community observations 2025-2026.

Примечание:
Community wiki прямо указывает, что многие tier-листы являются субъективными. Поэтому их ранжирование не переносится в ECHO SPHERE как истина. Переносятся механические принципы.

2. КОНЦЕПЦИЯ ECHO SPHERE
======================================================================

Жанр:
mobile arena survival / action roguelite / buildcraft.

Главная фантазия игрока:
«Я не просто прокачиваю героя. Я строю вокруг него живую боевую сеть, которая начинает вести себя как единый организм».

Главная механическая цепочка:

PLAYER CORE
  ->
SPHERES
  ->
MODIFIERS
  ->
NETWORK
  ->
GEOMETRY
  ->
RESONANCE
  ->
ARTIFACTS
  ->
SYNERGIES
  ->
PROTOCOLS
  ->
EVOLUTION
  ->
META

В Magic Survival основным объектом сборки является набор Magic.
В ECHO SPHERE основным объектом сборки является сеть.

Игрок должен принимать три типа решений:

A. ЧТО поставить?
Sphere / Ability / Passive / Artifact.

B. КАК ЭТО СОЕДИНИТЬ?
Позиция Sphere, дистанция, геометрия, порядок, активные связи.

C. КАК ПРЕВРАТИТЬ СБОРКУ?
Modifier, Evolution, Artifact, Protocol, Character identity.

======================================================================
7. SPHERE ARCHETYPES
======================================================================

STANDARD
Роль: универсальный DPS.
Одиночный projectile.
Стабильный target acquisition.
Сильна в Line.

SNIPER
Роль: single-target / boss.
Медленная атака, огромный impact.
Получает бонус от длинных линий.

CHAIN
Роль: multi-target.
Перескакивает между целями.
Сильна в Triangle.

AURA
Роль: proximity control.
Постоянная зона вокруг Sphere.
Сильна в Cluster.

SHOTGUN
Роль: burst / close range.
Много осколков.
Сильна при плотной сети.

ORBITAL
Роль: вращающиеся energy blades.
Получает бонус от Network radius.

PRISM
Роль: beam/refraction.
Луч может разделяться через links.

GRAVITY
Роль: pull/control.
Собирает врагов в узлы сети.

PULSE
Роль: periodic AoE.
Синхронизируется с Resonance pulses.

VOID
Роль: execution / distortion.
Поздняя high-risk Sphere.

======================================================================
8. SPHERE LEVELS
======================================================================

Каждая Sphere имеет 8 уровней.

L1: базовая механика.
L2: +20% core effect.
L3: behaviour modifier.
L4: secondary mechanic.
L5: network interaction.
L6: evolution choice.
L7: enhanced evolution.
L8: signature state.

Sphere upgrade никогда не должен быть просто «+5% damage» чаще двух раз подряд.

Примеры:

SNIPER L3:
Marked Target.

SNIPER L5:
выстрел через активную Line получает Breach.

SNIPER L6:
выбор:
- Execution Branch;
- Resonance Branch.

CHAIN L6:
- Arc Storm;
- Recursive Chain.

AURA L6:
- Compression Field;
- Regeneration Field.

======================================================================
12. LEVEL UP
======================================================================

Level Up является главным decision engine.

Обычная выдача:
3 карточки.

Категории:
- Sphere;
- Sphere upgrade;
- Modifier;
- Ability;
- Passive;
- Network upgrade;
- Resonance upgrade;
- special choice.

Распределение зависит от состояния build.

Принцип anti-RNG:

1. Не предлагать три бесполезных карточки.
2. Уже начатая Sphere имеет повышенный вес.
3. Build-defining modifier имеет повышенный вес, если есть compatible Sphere.
4. Если player долго не получал network option, вероятность network option растёт.
5. Если player не получил defensive tool, survival pool получает мягкий boost.
6. Не гарантировать конкретный предмет.
7. Не ломать ощущение discovery.

Protection:
- pity weight;
- duplicate suppression;
- dead-option suppression;
- build affinity;
- controlled randomness.

Reroll:
ограниченно.
Не превращать выбор в бесконечное «перекрути».

Ban:
поздняя meta-функция.

13. NETWORK
======================================================================

distance <= linkRadius

оба nodes active.

3.5 units.

- тонкая emissive линия;
- pulse при передаче энергии;
- colour/state зависит от Resonance.

Network metrics:
nodeCount
linkCount
averageLinkDistance
networkDensity
networkStability
resonanceCharge

CLUSTER BURST

======================================================================
18. ARTIFACT DESIGN RULES
======================================================================

Каждый новый Artifact обязан иметь хотя бы один ответ на вопрос:

1. Меняет Sphere?
2. Меняет Network?
3. Меняет Resonance?
4. Меняет enemy interaction?
5. Меняет reward loop?
6. Создаёт trade-off?
7. Создаёт новую build identity?

Если ответ «нет» на все вопросы, Artifact должен быть обоснован очень сильным экономическим/statistical эффектом либо не добавляться.

Цель каталога финальной версии:
80-120 artifacts.

Не делать 120 статических +5%.

Целевое соотношение:
~25% stat/support
~30% Sphere behaviour
~20% network/resonance
~10% control/survival
~10% economy/event
~5% transformational.

======================================================================
21. CHARACTERS
======================================================================

Characters are not simple skins.
Each character changes how the network is built.

1. SPHERIST
Generalist.
Starts with Standard.
Every 3 geometry completions grants temporary Core Overclock.

2. HUNTER
Single-target specialist.
Sniper starts one level higher.
Marked enemies reveal weak points.

3. ENGINEER
Network specialist.
+1 starting link range.
Moving Spheres refunds part of Resonance.

4. BERSERKER
Risk/reward.
Lower HP.
Higher damage.
Near-death states accelerate Resonance.

5. ALCHEMIST
Status specialist.
Burn/Freeze/Poison interactions are enhanced.
Three different status effects on one target create Transmutation.

6. ARCHITECT
Geometry specialist.
Can maintain one extra temporary node.
Geometry completion gives stronger bonuses but requires precise placement.

7. VOIDWALKER

- ordinary Artifact pool не содержит Legendary;
- Stella появляется после значимого boss event;

До появления Stella:

После Stella:

Ключевые исследовательские выводы:
1. Глубина возникает из взаимодействия нескольких слоёв, а не из количества отдельных предметов.

4. RNG должен создавать разнообразие, но не полностью блокировать build.
5. Формулы должны быть прозрачными и data-driven.
6. Визуальная выразительность особенно важна для читаемости большого количества одновременно работающих эффектов.

72. ГЛАВНЫЙ ПРИНЦИП ECHO SPHERE
======================================================================

Magic Survival отвечает на вопрос:

ECHO SPHERE должна отвечать на более широкий вопрос:
