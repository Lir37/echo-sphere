## Находки

- Исправлено подтверждённое расхождение для Android density ниже 1. Например, при 480 физических px и density 0.75 исходный CSS viewport имеет ширину 640 px, прежний нативный код давал 480 px. Теперь CSS/UI получает исходную положительную density, а разрешение Canvas отдельно применяет исходный clampDpr 1..1.75.
- Расчёт Canvas больше не дублируется вручную: calculateBackingSize и clampDpr механически экспортируются из неизменённого src/renderScale.ts и вызываются SourceCanvasSurface. Реэкспортирован весь граф из 52 модулей; содержательно изменился только Visual_renderScale.cs. Добавлены проверки DPR 0.75/1.25/3/NaN/Infinity. После исправления других подтверждённых расхождений в проверенном коде не осталось.
- Добавлены проверки CanvasStateChecks: фактически используемые overloads drawImage, положительные размеры изображений, solid fillText, поддерживаемые baseline, конечные координаты и достаточный буфер gradient stops. Они выполняются над теми же исходными 2663 сценариями.
- Расширен NativeLayerChecks: исходные mask/clip относятся к собственным кистям без потомков, screen находится внутри depth-композитора, multiply-виньетки используют только чёрный. Новый исходный случай потребует явного адаптера вместо молчаливого упрощения.
- Перепроверены подозрительные ограничения: Canvas shadows с нулевыми blur/offset не рисуются и в Chromium; фактический максимум gradient stops равен 5 при буфере 16; старые grid-column правила не используются текущими деревьями; fireTrails не заполняется также в исходнике. Эти случаи не исправлялись по предположению.
- Прежняя приближённая презентация не является активным визуалом: DrawPreviousMigrationInterface не вызывается, scene renderers скрыты cullingMask=0, текущий Canvas/UI рисуется исходными модулями.
