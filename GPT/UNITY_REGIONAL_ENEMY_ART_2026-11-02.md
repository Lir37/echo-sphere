## Ручная сборка APK

По прямому разрешению пользователя workflow unity-android-apk.yml снова
собирает настоящий Unity APK через GameCI. Старый android-apk.yml относится
к Capacitor и не используется для этого запроса. Обычные push-проверки отделены.

Ручной Unity workflow:
- Проверяет контракты и структуру проекта.
- Берёт точную версию из ProjectVersion.txt (6000.6.1f1), target Android.
- Использует существующие GitHub Secrets UNITY_LICENSE/EMAIL/PASSWORD;
  отсутствие конфигурации завершает job ошибкой, без ложного зелёного APK.
- Вызывает EchoSphereCiBuild.BuildAndroidApk, BuildOptions.None;
  исходный Development entry сохранён для диагностики.
- Проверяет существование Builds/Android/ECHO-SPHERE.apk и публикует его
  вместе с SHA256 и commit.txt в artifact echo-sphere-unity-apk-<SHA>.
- Поднимает shm контейнера до2GiB; время сборки ограничено90минутами.

Preflight обновлён под явно разрешённую ручную сборку; проверяет нативный
путь и исключает Capacitor/автоматическую APK-сборку при push.
Результат dispatch и фактический статус сборки фиксировать отдельно от CI.
Сам запуск workflow не означает готовый APK. Локально APK не собирается.
Пользовательские .utmp/Recovery14–18 не включаются в коммит.

Editor/тесты прошли. Проверить Actions, затем результат на телефоне.
