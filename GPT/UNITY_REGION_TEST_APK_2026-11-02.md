# APK для проверки регионов — 2026-11-02

По запросу пользователя все шесть обычных регионов доступны в отдельном тестовом APK.
Флаг ECHO_REGION_TEST_ACCESS передаётся только через BuildPlayerOptions.extraScriptingDefines.
В обычном Editor/CI/сборке без флага действует прежнее последовательное открытие.
Не записываются фиктивные победы/стабилизации, не выдаются Shards/ArchiveData.
Прогресс, контракты, Endless и Convergence сохраняют обычные условия.
Для возврата ограничений достаточно установки обычного APK поверх, очистка данных не нужна.
Сборка: scripts/build-unity-region-test.cs, IL2CPP/текущие настройки качества, BuildOptions.None.
Установка поверх существующей игры с сохранением данных; результат устройства фиксируется отдельно.
