# ECHO SPHERE — эталон персонажей v1.0

2026-10-29. Пользователь выбрал направление №1 и разрешил сразу внедрить.

Тонкие цветные/белые контуры, тёмные плоские внутренние области, свободное
пространство вокруг общего светящегося ядра. Без металлических фасок, объёмной
брони и гранёного корпуса. Ядро использует существующий игровой shader,
согласованный с остальным миром; это не новая модель освещения.

## Одна реализация рисунка

NativeCharacterContours хранит нормализованные Unity Mesh/Material по персонажу.
NativeWorldPlayer рисует их напрямую; прежний портрет тела и запасной
силуэт не участвуют в боевом пути. У частей нет отдельных blur-проходов.
Сохранены прежние bob/pulse, Spherist movement mirror/death pose и отдельные
индикаторы персонажей/щита; игровые правила, радиус16, RNG и сохранения прежние.

Портреты меню: Resources/EchoSphere/CharacterArt/<id>.png, прежние пути/GUID,
1254×1254, исходные настройки импорта и механизмы async/Lease. Они получены
из того же NativeWorldPlayer.DrawPortrait, без теней земли и статусов.
Рецепт: scripts/bake-unity-contour-characters.cs. При изменении геометрии/цветов
пересоздать все портреты этим скриптом и перепроверить меню.
