# ECHO SPHERE — эталон персонажей v1.0

2026-10-29. Пользователь выбрал направление №1 и разрешил сразу внедрить.

Тонкие цветные/белые контуры, тёмные плоские внутренние области, свободное
пространство вокруг общего светящегося ядра. Без металлических фасок, объёмной
брони и гранёного корпуса. Ядро использует существующий игровой shader,
согласованный с остальным миром; это не новая модель освещения.

## Одна реализация рисунка

NativeCharacterContours хранит нормализованные Unity Mesh/Material по персонажу.
NativeWorldPlayer рисует их напрямую; прежний портрет тела и запасной
силуэт не участвуют в боевом пути. У частей нет отдельных blur-проходов.
Сохранены прежние bob/pulse, Spherist death pose и отдельные
индикаторы персонажей/щита; игровые правила, радиус16, RNG и сохранения прежние.

Портреты меню: Resources/EchoSphere/CharacterArt/<id>.png, прежние пути/GUID,
1254×1254, исходные настройки импорта и механизмы async/Lease. Они получены
из того же NativeWorldPlayer.DrawPortrait, без теней земли и статусов.
Рецепт: scripts/bake-unity-contour-characters.cs, только Editor Play Mode.
Перед входом сохранить Editor prefs через backup-unity-gameplay-diagnostic-prefs.cs,
после Stop восстановить restore-unity-gameplay-diagnostic-prefs.cs. В Edit Mode
скрипт отказывается работать: runtime-owners освобождаются через deferred Destroy.
При изменении геометрии/цветов
пересоздать все портреты этим скриптом и перепроверить меню.
[Манифест итоговых PNG](VisualReferences/CharacterStyle-2026-10-29/implementation.json).

Старый GPT/character-art/approved-roster.png и прежние extraction prompts —
исторические концепты, не источник текущих игровых PNG. Новый APK и проверка
телефона в этот цикл не входят. Уже собранный78aec65e не содержит этих персонажей.

## Уточнение пользователя после первой реализации — 2026-10-29

Первый native лист признан слишком упрощённым: направление №1 не означает
пустые проволочные рамки. Сохранить цветные плоские вставки внутри стрелок/скоб,
внутренние направляющие, многослойный collar, сегменты энергии ядра, небольшие
боковые элементы. Мотивы и силуэты по персонажам остаются индивидуальными.
[Первоначальный упрощённый лист](VisualReferences/CharacterStyle-2026-10-29/roster-unity-initial-simplified.png)
хранится только для истории, он не является принятым эталоном.

Пользователь попросил убрать разворот корпуса при движении. Movement-facing
mirror удалён. Существующие bob/pulse/death pose и отдельные орбитальные эффекты
сохранены. Вместо разворота добавлен слабый след: шесть образцов пройденных позиций,
затухание0.18s,alpha≤0.065,без blur/ParticleSystem/RNG. Сброс при смене персонажа,
обратном ходе времени/длинном разрыве кадров/телепортации/гибели. В save не входит.
Это только оформление,никаких бонусов/урона/смены движения. Доработанный native
рисунок и след ещё требуют пользовательской визуальной приёмки.
