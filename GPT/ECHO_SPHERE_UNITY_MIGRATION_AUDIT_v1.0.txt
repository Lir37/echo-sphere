3. PORT / REWRITE POLICY
======================================================================

Port as pure C# contracts first:
- seeded run RNG;
- combat crit / contact grace rules;
- Formation Follow math;
- canonical Sphere roster;
- provider-neutral rewarded-ad eligibility.

Port as data/behavior domain:
- Sphere stats, level progression, 30 branch choices and 90 final choices;
- Modifiers, Abilities/evolutions, Artifacts, Sets, Protocols and Synergies;
- Characters/mastery; enemy roles and bosses; Regions; economy/persistence;
- deterministic build choices and run state.

Rewrite for Unity:
- Canvas renderer -> native SpriteRenderer, animation and VFX composition;
- React/CSS UI -> Unity UI;
- web input/camera/audio lifecycle -> Unity runtime;
- Capacitor wrapper -> Unity Android build.

Do not copy node_modules, dist, Capacitor build output, the legacy renderer,
unused reference crops, base64 image dumps, or large assets without verified
runtime usage. Gameplay state must not depend on visuals. Cosmetic random
effects must not consume run RNG.
