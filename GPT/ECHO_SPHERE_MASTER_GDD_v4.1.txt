MASTER GAME DESIGN & QUALITY SPECIFICATION
Version 4.1
Date: 2026-09-23

WORKING BRANCH
new-desing

DOCUMENT ROLE
Long-term product vision and quality target.

CORE PRODUCT
ECHO SPHERE is a mobile arena-survival game where the player controls a mobile Core and builds a living combat network of specialized Spheres.

DISTINCTIVE CHAIN
Sphere -> Modifier -> Network -> Geometry -> Resonance -> Artifact -> Protocol -> Evolution

DESIGN IDENTITY
The game rewards spatial thinking and build construction, not merely passive stat accumulation.

ART DIRECTION
FOLDED TECHNOLOGY / GEOMETRIC RESONANCE
- dark geometric structures;
- folded/angular forms;
- controlled emissive energy;
- links between entities;
- resonance pulses;
- transformations;
- visual complexity that communicates gameplay.

Avoid:
- generic neon soup;
- decorative sci-fi panels without purpose;
- complexity that does not communicate a mechanic.

PLAYER EXPERIENCE
The player should:
- understand the objective quickly;
- move responsively;
- make meaningful upgrade choices;
- care about Sphere placement;
- recognise their build;
- adapt to RNG without losing agency;
- experience meaningful boss/Stella events;
- understand why they died;
- want another run.

CONTENT PHILOSOPHY
Roadmap targets are minimum production milestones, not hard caps.

PRESERVATION RULE
Existing compatible content is part of the project asset base.
Do not delete an existing Sphere, enemy, boss, artifact, character, UI/system or asset merely because it is not required by the current roadmap phase.

If the current slice needs fewer choices:
- restrict the exposed pool;
- keep the underlying content;
- expand it when its roadmap phase arrives.

Example:
Five Sphere types may exist while the first controlled vertical-slice pool uses three. The extra compatible types remain available.

BUILD DEPTH
Desired layers:
- Sphere type;
- Sphere level/evolution;
- modifiers;
- network structure;
- geometry;
- resonance;
- artifacts;
- Pair Synergy;
- Artifact Sets;
- Protocols;
- characters;
- long-term meta.

ARTIFACT PHILOSOPHY
Artifacts should increasingly change behaviour:
- control;
- explosions;
- execution;
- projectile changes;
- Sphere behaviour;
- network changes;
- event triggers;
- build rules.
Avoid filling the catalogue with trivial percentage bonuses.

LEGENDARY / STELLA
Legendary rewards are intentionally scarce.
Stella is the main Legendary acquisition event after bosses.
Endless uses a configurable threshold around 25 minutes after which Stella transitions toward normal artifact rewards.

VERTICAL SLICE
First product candidate should demonstrate:
- movement;
- Dash;
- 3 primary Sphere choices;
- line/triangle/cluster;
- resonance;
- 6 modifiers;
- 4 enemy roles;
- boss;
- XP/level-up;
- 10-15 meaningful artifacts;
- 3 Artifact Sets;
- Stella;
- Legendary scarcity.

This is a proof target, not a deletion target.

PRODUCTION ORDER
GAMEPLAY -> BUILD DEPTH -> BALANCE -> READABILITY/VFX -> META -> CONTENT SCALE -> OPTIONAL/CONTROLLED 3D

QUALITY PRINCIPLE
Do not solve weak gameplay by adding more content or VFX.
Fix the underlying system, then expand.

SUCCESS CONDITION
Systems must create interesting decisions repeatedly.
The project should make players ask:
"What can I build this run?"
and later:
"What happens if I combine those things differently next run?"
