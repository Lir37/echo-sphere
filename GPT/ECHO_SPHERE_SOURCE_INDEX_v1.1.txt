CRITICAL PRESERVATION RULE
The roadmap is a production sequence, not a deletion list.

If a feature, content item, asset, Sphere type, enemy, UI element or system already exists and is compatible with the final ECHO SPHERE direction, KEEP IT unless there is a concrete documented reason to remove, replace or isolate it.

A feature being outside the current phase means it is not the current priority. It does not mean that existing compatible work must be deleted.

Example:
The first slice specifies 3 controlled Sphere choices: Standard, Sniper and Chain.
The repository already contains 5 Sphere types: Standard, Sniper, Shotgun, Chain and Aura.
Shotgun and Aura remain in the project. The first-slice pool may expose only the three target types without deleting the other two.
